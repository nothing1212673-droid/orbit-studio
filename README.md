# ORBIT Studio

A standalone, English-language portfolio concept with its own pages, assets, navigation and GitHub repository.

Live: https://nothing1212673-droid.github.io/orbit-studio/

## Pages

- index.html — home
- work.html — filterable selected concepts
- case-study.html?project=mori — detailed study; also forma and pulse
- studio.html — principles, services and process
- contact.html — project estimator and downloadable brief

## Motion

Slow orbital motion, mockup hover responses, chart entrance animation, case filters, section reveals and animated navigation. Motion respects prefers-reduced-motion; essential content and controls remain usable without animation.

## Source

No packages, build step or server dependency. style.css controls the visual system, common.js handles navigation and motion, and app.js contains site-specific interactions. Page links are relative and do not depend on another portfolio site.

To preview, serve this folder with any static HTTP server. Publish via GitHub Pages: main branch, / (root). Keep .nojekyll.

## Demo limits

A fictional independent studio and self-initiated projects. No real clients, testimonials or business results are claimed. Pulse is a static UI study. The estimator uses illustrative UAH figures, and the brief stays in this browser. This is a fictional brand made for a portfolio. Browser-local storage is used; storage failures fall back to the current page session. Prices remain in UAH.
